6. **`Config::load()` does not un-escape what `Config::write()` escapes** (src/Core/Config.php). `quote()` writes `"` as `\"` and `\` as `\\` inside double quotes, but `load()` only strips the outer quotes, so a value holding either character reads back changed (`S3cret"quote` → `S3cret\"quote`). The only writer is the CMS screen; `CmsConnection::validate()` now refuses passwords with `"` or `\` (and control characters) with a plain message, and `save()` re-reads the file and refuses to keep a password that does not round-trip. Suggested core fix so the restriction can go away: in `load()`, when the value is double-quoted, `stripcslashes`-style un-escaping of `\\` and `\"` only (keep single-quoted values literal) — and the matching `read_config` helper in install.sh (line ~131) should do the same.
7. **`Response::file()` buffers the whole file** (src/Core/Response.php:46 uses `file_get_contents`). Backups will grow once they carry the attachments tarball; `SystemController::downloadBackup` now streams files above 8 MB itself with `readfile()` after sending the same headers. A `Response::stream(string $path, …)` (or a callable body) in core would let the controller drop that special case.
