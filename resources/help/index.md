# Help: getting around Chroma

Chroma keeps track of the lab's projects and hands out codes. It replaces the internal-code log, the sell-number cross-reference, the security-ink code log and the project-tracking sheet.

## Easy and Expert mode

At the top of every page is a switch labelled **Easy** and **Expert**.

- **Easy** asks you one question at a time with big Next and Back buttons. Nothing is saved until you reach the review screen and confirm. This is the default.
- **Expert** puts the whole task on one page so you can work faster. It is the same task underneath; only the layout changes.

Your choice is remembered. You can switch at any point.

## The main areas

- **Projects**: the work the lab has been asked to do. One project can hold many colors or items.
- **Code lookup**: search any E number, sell number, customer or description. This replaces the cross-reference spreadsheet.
- **Code logs**: the list of codes under each prefix, newest first. This replaces the security and UV code logs.
- **Quick assign**: give out an E# or sell number without a project, for example a new sell number for a product that already exists.
- **Admin**: prefixes, users, lists, the legacy import, backups and updates.

## Need more?

Each page has short hints under the fields and a **?** you can press for a one-paragraph explanation. Pick a topic on the left for a longer walkthrough.
